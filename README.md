# 🏠 Sistema de Orçamento de Aluguel - Imobiliária R.M

Este é um programa interativo desenvolvido em Python para automatizar o cálculo e a simulação de orçamentos de locação residencial (Apartamentos, Casas e Estúdios). O sistema gera relatórios dinâmicos considerando regras de negócio como adicionais por quartos, vagas de garagem e descontos aplicáveis.

---

## 🛠️ Tecnologias Utilizadas

* **Python 3** (Lógica principal do sistema)
* **Biblioteca `csv`** (Para persistência e manipulação dos dados de orçamento)

---

## 🚀 Funcionalidades

* **Simulação de Locação:** Menu interativo para seleção do tipo de imóvel com valores base atualizados.
* **Cálculo Personalizado:** Adiciona custos extras com base na quantidade de quartos e presença de vaga de garagem.
* **Descontos Automáticos:** Aplicação de regras específicas (como desconto de 5% para apartamentos sem crianças).
* **Exportação de Dados:** Integração com arquivos CSV para salvar os orçamentos gerados.
